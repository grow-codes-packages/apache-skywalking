# TypeScript example

```sh
(cd ../../typescript && npm install && npm run build)
npm install
GROW_APACHE_SKYWALKING_URL=http://127.0.0.1:12800 npm start   # OAP REST/GraphQL port
```

Replace the `file:` dependency in `package.json` with a version (`npm install @grow-codes/apache-skywalking`)
to run it against the published package.
